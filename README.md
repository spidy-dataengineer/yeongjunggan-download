# 영중간 내려받기

영어·중국어 표현 퀴즈 앱 **영중간**의 설치 파일만 올리는 곳이에요. 소스 코드는 없어요.
새 버전이 나오면 자동으로 올라오고, 아래 주소는 늘 최신 버전을 가리켜요.

| 기기 | 받기 | 참고 |
|---|---|---|
| PC (윈도우) | [PC 앱 받기](https://github.com/spidy-dataengineer/yeongjunggan-download/releases/latest/download/yeongjunggan-pc-setup.exe) | 일하는 중에 문제 창이 떠요. 처음 실행할 때 Windows 경고가 뜨면 "추가 정보 → 실행"을 눌러요 |
| 안드로이드 | [APK 받기](https://github.com/spidy-dataengineer/yeongjunggan-download/releases/latest/download/yeongjunggan.apk) | "출처를 알 수 없는 앱" 설치를 허용해야 해요. 크롬에서 웹을 "앱 설치" 해도 돼요 |
| 아이폰·그 밖 | [웹으로 열기](https://yeongjunggan.pages.dev) | 사파리 공유 버튼 → "홈 화면에 추가" |

버전별 바뀐 점은 [Releases](https://github.com/spidy-dataengineer/yeongjunggan-download/releases) 와 앱의 내 정보 → 앱 버전에서 볼 수 있어요.
문의는 앱의 내 정보 → 문의로 보내 주세요.
